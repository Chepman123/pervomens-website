Pervomens Games – Frontend Website

This is the frontend for the official website of Pervomens Games, an indie game studio.
The website showcases the studio’s games, news, and updates, providing users with a sleek, interactive experience.

🛠 Technologies Used

React

React Router


🚀 How to Run Locally
1️⃣ Clone the repository
git clone https://github.com/username/pervomens-website.git

2️⃣ Install dependencies
cd client
npm install

3️⃣ Run the development server
npm run dev


Open http://localhost:5173
 in your browser to see the website
